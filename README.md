## 📌 About This Repo

I completed a full Data Analytics curriculum (SQL, Python, Excel, Power BI, statistics, ML) and built several end-to-end projects — then stepped away from daily practice for a while. This repo is where I'm rebuilding that fluency, deliberately and from scratch, before going back into the job market.

**The rule I'm following:** concepts come back fast. Typing fluency doesn't — it has to be rebuilt by hand, query by query. So everything committed here was written and run by me, not generated for me.
